**From a view to Python**
- **Copy View as Code** (Edit menu): the current view (filters, sort, columns) as DuckDB SQL, Polars or pandas, ready to paste. S3 code uses your AWS profile, never keys.
- **Open in marimo** (⌘⇧M / Ctrl+Shift+M): the view as a [marimo](https://marimo.io) notebook, in a Parquetry window or your browser (Settings ▸ Notebooks). It runs through [uv](https://docs.astral.sh/uv/) with nothing else to install, and you can add any library to it. Polars or pandas, your choice.
- **File ▸ Open Notebook…** and **Recent Notebooks** reopen saved notebooks.

**S3 that explains itself**
- When credentials are the problem, Parquetry says so and offers the fix: choose one of your AWS profiles, set one up, or, when an SSO session has expired, **Sign In** (runs `aws sso login`) and pick up where you left off: the S3 browser, a tab that couldn't open, the SQL console, a comparison.
- Public buckets open without any credentials, so the "Anonymous" setting is gone.

**Look and feel**
- A new start page: the app icon, your recent files with their type and when you opened them, and your notebooks side by side.
- The macOS disk image opens on a hand-drawn install plan.

**Install / update**
- macOS: the app updates itself, or `brew upgrade --cask parquetry`.
- Windows: `scoop update parquetry` (first install: `scoop bucket add tiroger https://github.com/tiroger/scoop-bucket` then `scoop install parquetry`).
