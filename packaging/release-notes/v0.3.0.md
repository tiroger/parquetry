**A fresh look**
- New default dark theme, **Navy & Oak**, matching the icon. **Slate** is a second dark option (View ▸ Appearance or Settings), and the light theme got the same polish.
- Column headers show a type badge (# for numbers, Aa for text, Dt for dates, …), charts coloured by kind of data, and a thin line for the share of nulls.
- A cleaner title (file name, folder, file facts), a segmented Data / Columns / Metadata / SQL switch, and filter and sort chips right next to it.
- Subtle row striping, an accent outline on the selected cell, and no grid lines past the last column.
- The status bar shows the sort and, when several cells are selected, their sum, average, min and max.

**Platforms**
- macOS builds now run on Intel Macs as well as Apple Silicon.
- Windows: monospace text uses the system's font instead of a macOS-only one.

**Install / update**
- macOS: the app updates itself, or `brew upgrade --cask parquetry`.
- Windows: `scoop update parquetry` (first install: `scoop bucket add tiroger https://github.com/tiroger/scoop-bucket` then `scoop install parquetry`).
